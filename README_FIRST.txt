IMPORTANT BEFORE LAUNCH:

Run locally:
- Open index.html in a modern browser for a static preview.
- For best results, serve the folder with any simple static web server.

PRODUCT MANAGER UPDATE:
- Use the “Manage products” button in the top header to open the editor.
- Add products or select an existing product from the list to edit it.
- Upload/change a product image, update selling/old price, brand, category, description,
  stock status and featured status, then choose “Save product”.
- Product changes are stored in this browser's local storage for this preview. They are
  not synced between devices or published to a live website until connected to a backend.
- For reliable image storage, use reasonably sized JPG/PNG/WebP images.

ADMIN DASHBOARD + REPAIRS + CHECKOUT EXTENSIONS (LATEST)
- No Admin Login button is displayed to customers. Admin opens the private access panel with Ctrl + Shift + A, then signs in to reveal Admin Dashboard and Website Editor controls.
- Demo credentials: username `admin`, password `Landmark@2026`.
- Change the demo credentials in app.js before publishing. This front-end-only login is a preview gate, NOT secure authentication. Production admin access must be validated by a server/backend.
- Admin Dashboard includes locally saved Orders, Stock overview and Repair requests.
- Manage Products supports add/edit/delete, image upload, current/old price, brand, category, description, featured flag and stock quantity.
- Customers can submit Computer/Laptop, CCTV and POS repair requests; the request is saved in this browser and prepared for WhatsApp.
- Cart order attempts are recorded in this browser's local storage and sent to WhatsApp. No server-side order processing or stock reservation is active.

Never collect card details in this static site.
- Product edits, orders, stock and repair enquiries are browser-local only. They do not sync across devices and can be lost if browser data is cleared. A production launch needs a secure backend/database, admin roles, image storage and payment integration.
